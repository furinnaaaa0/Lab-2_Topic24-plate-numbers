## Проверка и поиск синтаксически корректных государственных регистрационных знаков транспортных средств


## Описание проекта

Программа предназначена для проверки соответствия государственных регистрационных знаков транспортных средств заданному формату, а также для поиска таких номеров в текстовых данных.

Проект выполнен на языке Python.

 

## Возможности программы

 

- Проверка одного регистрационного знака на соответствие заданному формату.

- Поиск регистрационных знаков в произвольном тексте.

- Поиск номеров в локальных текстовых файлах.

- Получение текста веб-страниц и поиск номеров в их содержимом.

- Нормализация регистра букв и удаление пробелов.

- Обработка ошибок при работе с файлами и веб-страницами.

 

## Проверяемый формат
 

Программа проверяет номера следующей структуры:

- Одна буква.

- Три цифры.

- Две буквы.

- Две или три цифры региона.


Допустимые буквы: А, В, Е, К, М, Н, О, Р, С, Т, У, Х.
 

Для удобства программа также распознаёт соответствующие латинские символы и их смешанные варианты.

 

** Важно: ** поддержка латинских символов является особенностью реализации программы и не означает, что такие символы разрешены на физических российских регистрационных знаках.
 

## Структура проекта

 

- `main.py` - главное меню и управление работой программы.

- `validator.py` - проверка и нормализация регистрационных знаков.

- `search.py` - поиск регистрационных знаков в тексте.

- `source\_handler.py` - чтение локальных файлов и загрузка веб-страниц.

- `tests.py` - модульные тесты программы.

- `requirements.txt` - список необходимых зависимостей.

## Установка и запуск
 

Для работы программы необходим Python 3. 

1. Скопировать репозиторий

2. Перейти в каталог проекта
`cd Lab-2\_Topic24-plate-numbers`
3. Установить необходимые зависимости:
`pip install -r requirements.txt`
4. Запустить программу:
`python main.py`

## Использование
После запуска программы отображается главное меню:

1. Проверить один номер.

2. Найти номера в тексте.

3. Найти номера в файле.

4. Найти номера на веб-странице.

0. Выход.
 
Выберите нужный пункт и следуйте инструкциям программы.

## Ограничения

Программа проверяет только синтаксическое соответствие регистрационного знака заданному формату.

Она не выполняет следующие действия:

- Не проверяет существование регистрационного знака в базе данных ГИБДД.
- Не определяет владельца транспортного средства.
- Не распознаёт номера на изображениях.
- Не проверяет специальные типы регистрационных знаков.
